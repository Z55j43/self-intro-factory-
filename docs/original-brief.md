## 各场景特点、侧重点、篇幅、语气

核心逻辑：自我介绍本质是「给对方想要的信息」，不同场景，听众关心的东西完全不一样，按正式度从高到低划分，一共 4 大类，下面细分场景。

---

## 一、正式考核 / 选拔类（最高正式度）

**目标**：证明你符合要求、有能力，说服考官 / 面试官，偏理性展示。

### 场景 1：求职面试（校招 / 实习 / 社招）

- **篇幅**：1～3 分钟（口头）；简历配套简短版 30 秒
- **受众**：面试官，关心：能不能干活、稳定性、匹配岗位
- **侧重点**：和岗位相关的经历、能力、成果，弱化无关爱好
- **特点**：结构化。公式：基本信息 → 过往经历（做了什么 + 拿到什么结果）→ 优势 → 求职动机
- **避雷**：不要流水账，少说个人生活琐事。

### 场景 2：考试口语（四级 / 六级 / 雅思 / 考研复试）

- **篇幅**：30 秒～1 分钟（严格限时！）
- **受众**：考官，关心：流利度、发音、语法，信息简单清晰即可
- **侧重点**：基础个人信息 + 学习相关内容，简单爱好
- **特点**：简单、好背诵、词汇不要太难，不要长难句堆砌；四级口语常考版本：姓名、学校专业、家乡、兴趣，一句话简单说未来计划。

### 场景 3：竞赛 / 答辩 / 评优竞选（奖学金、比赛、班委竞选）

- **篇幅**：1～2 分钟
- **侧重点**：成绩、项目、获奖、责任心，突出优势与价值
- **特点**：有说服力，可带一点点个人信念，适合现场打动评委同学。

---

## 二、校园学习 / 团队场景（中等正式，最常用）

**目标**：快速建立身份，让队友 / 同学知道你是谁、能做什么。

### 场景 1：课程小组、项目团队初次见面（小组作业、科创团队、实验室）

- **篇幅**：30 秒左右
- **受众**：队友
- **侧重点**：姓名 + 专业 + 你擅长什么、可以承担哪部分工作
- **特点**：务实。例：我是谁，软件工程，擅长写代码，后续可以负责开发部分；爱好一句话带过就行。

### 场景 2：开学第一课、新生班会、班级自我介绍

- **篇幅**：20～40 秒
- **侧重点**：姓名 + 家乡 + 简单爱好，拉近同学距离
- **特点**：轻松友好，不用展示很强能力，让人记住你即可。

---

## 三、社交认识类（低正式，生活化）

**目标**：破冰，交朋友，留下亲切印象，不考核能力。

### 场景 1：认识新朋友、社团招新线下、聚会

- **篇幅**：10～20 秒，超简短
- **侧重点**：名字 + 简单兴趣
- **特点**：轻松随意，可以带一点小幽默。例：大家好，XX，平时喜欢看动漫、打游戏，很高兴认识大家。

### 场景 2：线上社群（微信群 / QQ 群）

- **篇幅**：一句话极简版
- **侧重点**：名字 + 身份 + 来这个群的目的。例：大家好，我是 XX，软件工程，来一起交流算法。

---

## 四、特殊简短场景（极简，10 秒以内）

**目标**：仅告知身份，不需要额外信息。场景：临时开会、线上会议开场、临时组队。

- **篇幅**：5～10 秒
- **模板**：大家好，我是 XX。
- **特点**：只报名字，除非被要求，不额外多说。
