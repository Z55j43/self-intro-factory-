# 「20 问 → 双语自我介绍」这个想法，GitHub 上有人做过吗？

**调研日期**：2026-10-02
**调研方法**：GitHub Search API（repositories 端点）+ 多轮网页检索

---

## 结论先行

**有人做过，而且不止一个。但——没有一个项目做成你想要的那个精确形状。**

拆开看，这个想法由三个零件组成：

| 零件 | 开源实现情况 |
|---|---|
| ① 一组帮你认识自己的问题 | **非常成熟**，几十个项目，最狠的一个有 990 道题 |
| ② 用你的回答生成一篇"自我介绍" | **有，但要么输入是简历不是自省，要么没人维护** |
| ③ 同一份自我，输出中英两版**成品** | **基本是空白** |

也就是说：**单点都有人做，组合起来没人做全**。下面把搜到的都列出来，你自己判断值不值得做。

## 一、项目清单（按相关度排序，★ 数据来自 GitHub API 实时拉取）

### 🟢 第一梯队：想法高度重合

#### 1. `Forlives/21-day-self-interview` — ★110 · fork 40 · Python · MIT · 更新 2026-06
> 🪞 一个存在主义心理学 AI 咨询师，连着 21 个晚上，每晚问你 3 个问题，记住你所有的回答，在第 7、14、21 天把你自己的话织成一幅画像还给你。**中英双语。**

**这个是最接近的。** 甚至它的宣传语都跟你说的是一回事：「大多数自省工具失败是因为没有记忆——今晚写的，沉进本子里再也见不到」。而且明确做了 zh/en 双语。

**但它和你的想法有三个实质区别：**
- **周期**：21 天 × 3 问 = 63 问，是**渐进式**的。你要的是**一次性 20 问、当场出稿**。
- **产出**：它产出的是「你自己的话的镜像」（让你看见自己），**不是一篇能拿去用的自我介绍**。
- **形态**：Hermes Agent 的 skill，锁死在那个 agent 生态里跑，不是独立工具。

👉 它证明了「问题 + AI + 双语 + 自我认识」这个组合有人愿意给 star，但它走的是"深度慢炖"路线，你那条"快出成品"的路是空的。

---

#### 2. `Gogolian/preserver` — ★22 · Python · MIT · 更新 2026-04
> 开源、本地、重隐私的 LLM 数据采集工具，为你的「数字孪生」攒料。**990+ 道题，33 个类别**，支持导出 JSONL 直接拿去微调模型。

**最全的题库**。33 类涵盖童年、目标、信念、性格、关系、偏好、职业、爱好、记忆、技术、灵性、社媒、人生哲学、观点……

**但它的目的不是让你读一篇自我介绍**，而是给未来的 AI 攒语料。输出是 `{"instruction":..., "output":...}` 这种训练格式。题量太大（990 道），根本不是一个"30 分钟能答完"的问卷。

👉 **如果你想扩充题库，这是最值得抄的参考**。但产品目标完全不同。

#### 3. `baoyudu/digital-self` — ★11 · MIT · 更新 2026-04
> 通过深度 AI 对话，把你自己建成一堆 markdown 文件——`me.md`（一页自我画像）、`identity/`、`capabilities/`、`patterns/`、`relationships/`、`story/`、`inner-world/`，丢进任何 AI agent 的上下文里，让它一开始就"认识你"。

设计哲学很有意思，README 里一句话几乎就是你的立项理由：**「过程本身就是产品。被 AI 深度访谈，这件事本身就是自我探索的工具，文件只是附赠。」**

**区别**：它没有固定问题清单，是自由对话式的访谈；产出是给 AI 读的结构化文件，不是给人读的自我介绍。

### 🟡 第二梯队：部分重合

#### 4. `forsonny/deep-discovery` — ★104 · MIT · 更新 2026-04
> 一个结构化的自我审问框架：围绕一个主题，用 **100 个层层递进的问题**往上叠，每个问题都建立在前一个答案之上。

★104，热度不错。但它是**方法论/prompt 框架**，只负责"问"，完全不负责"写成文"。

👉 值得看的是它的**递进逻辑**——问题之间咬合。你的 20 问是并列的，它的 100 问是累进的。两种设计各有优劣：并列好答、累进更深。

#### 5. `asdxzc2/inner-field` — ★0 · JavaScript · 无许可 · 更新 2026-10-01
> 225 天，每天问一个问题。用**八个心理学量表**（焦虑、韧性、正念、自尊、情绪调节、感官敏感度、压力、积极情绪）给你的回答打分，追踪你的心理状态变化。答完全部 225 题后，AI 给你生成**一封个性化的信**。中英双语，支持 Windows 应用 + PWA，可离线。

**中文项目**，工程完成度不低（README 写得非常细）。产出是"一封信"而不是"自我介绍"，周期是 225 天。★0 说明**没人发现它**。

👉 它的思路值得借鉴：**给答案打分 / 加量表维度**，让结果从"文字"升级为"可量化的自我画像"。

## 三、真正的空白在哪（如果你要做，往这四个点打）

### 1️⃣ 一次性出稿，而不是"用三周换深度"
所有做得好的项目（★110 的 21-day、★104 的 deep-discovery、990 题的 preserver）都在往**更深更长**走。没人认真做"**30 分钟答完，立刻拿到一篇能用的稿**"。

这是真实需求：你要给社团写自我介绍、要填个人主页、要做一次自我梳理——你不会为此连续写 21 天日记。

### 2️⃣ 问题要**为成文而设计**，不是为反思而设计
现有项目的问题都是通用反思题（"你的核心价值观是什么"）。答完还要再想办法组织成文章。

**二十问的每一题都直接产出一个句子片段**——第 1 题产出"我是___"，第 7 题产出"我不打算妥协的是___"。答完即成型，不需要第二次组织。这个设计上的耦合，我在开源里没找到对标。

### 3️⃣ 双语不是"翻译"，是"两种自我表达"
`21-day-self-interview` 和 `inner-field` 都号称双语，但它们的双语是**界面和题库**双语（同一套题有中英两个版本），不是**把同一个人的回答产出两篇地道的成品**。

中英自我介绍不是互译关系——英文版要重写句式、调整语气、删掉中文里那种含蓄的铺陈。**一件"同一自我 × 两种语言"的成品，开源里没有。**

### 4️⃣ 零依赖、纯本地、不用 API key
几乎每个项目都要求：OpenAI key（biography-system）、Hermes Agent 框架（21-day）、Claude Code（baoyudu）、Ollama（ikigai-compass）。

**纯前端、打开浏览器就能用、答案不离开本机、不用配任何 key 的**——极少。而这恰好是"自我解剖"这件事最需要的隐私姿势：你不会愿意把第 20 题的答案上传到别人的服务器。

## 四、诚实的风险评估

**这个想法"新"吗？** 不新。任何一个零件都有人做过，赛道不冷。

**但"这个精确形状"有人做成了吗？** 没有。最接近的两个——`biography-system`（功能全对上了，★0 废弃）和 `2025Sum2selfQuestions`（20 问 + 生成画像，★0）——都是没人维护的小项目。

**这意味着两种可能，得自己判断：**
- 🤔 **是没人做过的好机会**：需求真实，实现的都是练手项目，说明没人认真做。
- 🤔 **是没人要的东西**：做过的人都没坚持下去，说明"一次性生成"这件事的实际使用频率很低——人只在特定时刻（求职、入学、社团）才需要一次，用完就走，不构成持续使用的产品。

我的判断偏向后者多一点，**但作为个人工具它完全值得做**：它成本极低（一个 HTML 文件），而收益是你真的被问了一遍这 20 个问题。`21-day-self-interview` 的作者在 README 里写的这句话，我认为是对的——

> 「过程本身就是产品。被深度访谈这件事本身，就是自我探索的工具，产出只是附赠。」
